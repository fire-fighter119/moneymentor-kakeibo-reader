# MoneyMentor わたしの家計簿

登録不要のブラウザ家計簿です。記録は利用者の端末内（IndexedDB）に保存します。

- 日付・金額・費目・最低限／ゆとりを入力
- 合計を最低限とゆとりの2件に分割
- 月別・年別・費目別の集計
- 費目の追加、記録の削除
- JSONバックアップと重複を除いた追加復元

## データについて

家計データを運営者へ送信する機能、アクセス解析、外部ライブラリはありません。
サイト配信元には通常のページアクセスが発生します。データはURLのホストごとのブラウザ保存領域に保持されます。
ブラウザのデータ削除、機種変更、保存領域の削除で記録が失われることがあります。定期的にバックアップしてください。暗号化ファイルではないため、バックアップを他人へ渡さないでください。
別端末・別ブラウザとの自動同期、ログイン、アプリ内ロックはありません。プライベートブラウズや共有端末での利用は避けてください。

## 起動

静的HTTPサーバーでこのフォルダーを配信します。ビルド・インストール不要です。

## 自由の家計簿
選択年の家計簿から最低限・ゆとりを自動集計。最低限の必要資産＝最低限支出×25、ゆとり込みの必要資産＝全支出×25。4％の仮定、税金・値動き・年金等の他収入を考慮しない概算。未入力年は金額を表示しません。年途中の入力を年換算しないため、1年分入力して利用してください。
予算入力画面は廃止。旧budgetデータは互換性のため保存/バックアップ内で維持し、計算には使いません。
記録一覧は選択期間内で保存配列の末尾（新しい入力）から表示。支出日順ではありません。復元で追加された記録は追加順になります。
